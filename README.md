# Raspberry-Pi-Robot-Arm
## Overview
An automated robot arm designed to monitor soil conditions and deliver watering to houseplants, intended for when the plants would be left alone for a long period of time.
<img src=https://github.com/MaxMembrino/Raspberry-Pi-Plant-Caretaker/blob/main/Robot.jpg>
## Hardware
**Raspberry Pi 3:** Handles the sensor data from the moisture sensors in the plant pots and decides when one needs watering
**PCA9685:** Manages 6 servos (providing 5 degrees of freedom)
**Laser Cut components** Cut from acrylic as they are stronger than 3D printed parts

## Features
- Automated soil monitoring
- Targeted watering
- Gear driven gripper capable of holding different tools needed for taking care of the plants
